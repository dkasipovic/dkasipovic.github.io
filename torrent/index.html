Paste a magnet link, pick a file, and it plays right here. Everything runs in this tab — no server, no upload, nothing installed. Because a browser can only reach peers over WebRTC, this finds peers for torrents that are seeded by WebTorrent-capable clients or that carry a web seed.     Why a magnet may find no peers

    1. A tab cannot open TCP or UDP sockets, so it can only reach peers over WebRTC, announced on wss:// trackers. Every browser torrent client has this limit.
    2. It works with torrents seeded by a WebTorrent-capable client — a browser tab, WebTorrent Desktop, Vuze, BiglyBT — and with magnets carrying a web seed (ws=), which is fetched over plain HTTPS and needs no peers at all. The demo is one of those.
    3. Playback uses the browser's own decoder: MP4, MOV, WebM and (outside Firefox) MKV play. AVI, MPEG and WMV do not, and H.265 or AC3 inside an MP4 usually will not either. Those get a download link.
    4. An MP4 whose index sits at the end of the file cannot start until it has downloaded in full. That is how the file was made, not a fault here.
    5. Pieces are held in private browser storage while you watch and are deleted when you press Stop & clear or close the tab. Nothing is kept.
